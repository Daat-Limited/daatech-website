# DAATECH Public Website

A simple, static public-facing website for DAATECH — Digital Trust Infrastructure.

## Purpose

This site is intentionally independent from the DAATECH DTI application. It can be published on GitHub Pages while the actual platform continues development.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — minimal placeholder JavaScript
- `assets/` — future local images, logos and other assets

## Deployment

Upload the contents of this folder to a GitHub repository and enable:

**Settings → Pages → Deploy from branch → main → / (root)**

No backend, database or build process is required.
